# Configuration Reference

The **`nmk-rust`** plugin handles the configuration items listed in this page.

All of them are initiliazed with convenient default values, so that you don't need to setup them for a default working behavior. You can anyway override them in your projet if you need to fine tune the plugin behavior. [Some items](extend.md) are specifically designed to be extended by **`nmk`** projects and plugins.

---

## Paths and files

---

(rustSrcFolder)=

### **`rustSrcFolder`** -- Rust source code folder

| Type | Default value                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------- |
| str  | [${sourceDir}](https://nmk-base.readthedocs.io/en/stable/config.html#sourcedir-source-base-directory) |

This is the path **`nmk`** will browse to find source files.

(rustSrcFiles)=

### **`rustSrcFiles`** -- Rust source files

| Type       | Default value                                                   |
| ---------- | --------------------------------------------------------------- |
| list[Path] | Generated by {py:class}`nmk_rust.resolvers.RustSourcesResolver` |

This is the list of source files for this rust project (found in **{ref}`${rustSrcFolder}<rustSrcFolder>`**).

(rustTargetFolder)=

### **`rustTargetFolder`** -- Rust target binary folder

(rustConfigFolder)=

### **`rustConfigFolder`** -- Rust (cargo) configuration folder

| Type | Default value        |

| str  | ${PROJECTDIR}/.cargo |

(rustConfigFile)=

### **`rustConfigFile`** -- Rust (cargo) configuration file

| Type | Default value                                          |
| ---- | ------------------------------------------------------ |
| str  | **{ref}`${rustSrcFolder}<rustSrcFolder>`**/config.toml |

This is the **`cargo`** [configuration file](https://doc.rust-lang.org/cargo/reference/config.html) for the current project. It is generated by the **{ref}`rust.config<rust.config>`** task.

| ---- | ------------------------ |

This is the **`cargo`** package [manifest file](https://doc.rust-lang.org/cargo/reference/manifest.html) for the current project. It is generated by the **{ref}`rust.manifest<rust.manifest>`** task.

(rustVersion)=

### **`rustVersion`** -- Rust package version

| Type | Default value                                                   |
| ---- | --------------------------------------------------------------- |
| str  | Generated by {py:class}`nmk_rust.resolvers.RustVersionResolver` |

By default the rust package version (to be generated in the **{ref}`${rustManifestFile}<rustManifestFile>`** manifest file) is guessed from the current [${gitVersion}](https://nmk-base.readthedocs.io/en/stable/config.html#gitversion-git-version):

- If current project version control is on a git tag (not dirty), Rust package version will be exactly set to this tag<br>
  e.g. with `gitVersion: 1.2.3`,<br>
  we'll get `rustVersion: 1.2.3`<br> <br>

- Otherwise, next version is guessed from both last git tag and configured **{ref}`${rustVersionIncrement}<rustVersionIncrement>`** increment:
  - if increment is set to **1.0.0**, major version will be incremented, and remaining minor and patch digits will be reset to 0<br>
    e.g. with `gitVersion: 1.2.3-3-g1234567` and `rustVersionIncrement: 1.0.0`,<br>
    we'll get `rustVersion: 2.0.0`<br> <br>

  - if increment is set to **0.1.0**, minor version will be incremented, and remaining patch digit will be reset to 0 (major digit is unchanged)<br>
    e.g. with `gitVersion: 1.2.3-3-g1234567` and `rustVersionIncrement: 0.1.0`,<br>
    we'll get `rustVersion: 1.3.0`<br> <br>

  - if increment is set to **0.0.1**, patch version will be incremented, and major/minor digits are unchanged<br>
    e.g. with `gitVersion: 1.2.3-3-g1234567` and `rustVersionIncrement: 0.0.1`,<br>
    we'll get `rustVersion: 1.2.4`<br> <br>

```{note}
This version guess has been introduced to avoid generating a dirty **Cargo.toml** file each time a new commit is made on a given Rust project. Since cargo doesn't provide a way to detect dynamically the package version (it *must* be written verbatim in the **Cargo.toml** file), this is the best tradeoff to get a generated version somehow related to the existing git tags, which is a convention of **`nmk`** projects.

Obviously you need to forecast a bit regarding the next tag you'll push on your project. If since the last tag you change your mind about the next version (e.g. a patch version rather than a minor evolution), you just need to make a new commit with an override of **{ref}`${rustVersionIncrement}<rustVersionIncrement>`** to refresh the guessed next version.
```

```{warning}
If you create a tag which doesn't match the guessed version in the generated **Cargo.toml** file, this one will be updated during the build, but then your project will be dirty, and the build will fail in CI.
```

## Dependencies

---

(rustDependencies)=

### **`rustDependencies`** -- Rust package dependencies

| Type          | Default value |
| ------------- | ------------- |
| dict[str,str] | {}            |

This is the map of current package operational dependencies versions (indexed by name) to insert in the [dependencies](https://doc.rust-lang.org/cargo/guide/dependencies.html) section when generating **{ref}`${rustManifestFile}<rustManifestFile>`** manifest file.

---

(rustDevDependencies)=

### **`rustDevDependencies`** -- Rust package development dependencies

| Type          | Default value |
| ------------- | ------------- |
| dict[str,str] | {}            |

This is the map of current package development dependencies (used by tools and tests) versions to insert in the [dev-dependencies](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html#development-dependencies) section when generating **{ref}`${rustManifestFile}<rustManifestFile>`** manifest file.

---

(rustBuildDependencies)=

### **`rustBuildDependencies`** -- Rust package build dependencies

| Type          | Default value |
| ------------- | ------------- |
| dict[str,str] | {}            |

This is the map of current package build dependencies (used by build scripts) versions to insert in the [build-dependencies](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html#build-dependencies) section when generating **{ref}`${rustManifestFile}<rustManifestFile>`** manifest file.

---

(rustFetchStampFile)=

### **`rustFetchStampFile`** -- Dependencies fetch stamp file

| Type | Default value                                                                                                    |
| ---- | ---------------------------------------------------------------------------------------------------------------- |
| str  | [${outputDir}](https://nmk-base.readthedocs.io/en/stable/config.html#outputdir-output-base-directory)/.rustfetch |

Stamp file updated each time fetch task is executed (for incremental build).

---

(rustFetchExtraArgs)=

### **`rustFetchExtraArgs`** -- `cargo fetch` extra command line args

| Type      | Default value |
| --------- | ------------- |
| list[str] | []            |

List of **`cargo fetch`** command extra arguments when formatting code.

---

(rustIgnoredLockfile)=

### **`rustIgnoredLockfile`** -- Ignored lock file

| Type       | Default value                                                           |
| ---------- | ----------------------------------------------------------------------- |
| list[Path] | Generated by {py:class}`nmk_rust.resolvers.RustIgnoredLockfileResolver` |

This is resolved:

- either to project's **Cargo.lock** file if the buildenv is not locked
- or an empty list otherwise

This item is contributed to [${gitIgnoredFiles}](https://nmk-base.readthedocs.io/en/stable/config.html#gitignoredfiles-git-ignored-files-list) to be added to generated **.gitignore** file.
